# GoGoGuard 系统考古笔记

本目录是 `gogoguard_robot_inspection_v2_field` 的持续审计工作台。它记录证据、矛盾和未确认项，不把行业惯例当作当前系统事实，也不把“代码存在”写成“已部署/已现场验证”。

## 状态

- ✅ 已确认：有启动关系、完整代码、配置、运行回执或数据流的交叉证据。
- 🟡 高概率：代码关系强，但仍缺启动、部署或现场证据中的一环。
- ❓ 未确认：证据不足或相互矛盾。
- ⚪ 非当前主链路：代码存在，但当前入口未使用。
- 🧹 疑似历史遗留：很可能为旧实现或临时兼容，尚未批准删除。

## 证据规则

重要结论至少记录：结论、状态、来源文件、类/函数或入口、配置、上游、下游和尚缺证据。部署事实必须区分源码 commit、镜像 tag、镜像 digest、安装、静态启动、真实运动和产品验收。

## 当前审计边界

- 唯一活动产品仓库：本仓库。
- 只读审计运行代码、配置、现场资料和忽略目录中的资产元数据。
- 不连接或移动机器狗，不连接云 worker，不触发 SaaS 写操作。
- 不修改运行模块、参数、地图或部署；发现问题先记录。
