# 现场工作台操作说明

本文只说明现场按钮和安全操作。系统原理、模块和开发规则见[架构与开发者交接总文档](INSPECTION_SYSTEM_TECHNICAL_GUIDE.md)，当前机器狗版本和已知问题见 [PROJECT_STATE.md](../PROJECT_STATE.md)。

## 1. 启动前

1. 确认 Mac 与机器狗网络连通，机器狗处于安全姿态，现场有人持手柄看护。
2. 在仓库根目录运行 `make workstation`。
3. 浏览器打开 `http://127.0.0.1:8080/`。
4. 顶部确认机器狗在线、Livox/IMU 有频率、相机可预览、没有上一任务残留。
5. 需要平台资产上传时，在启动工作台进程前通过环境变量注入设备 token；不要把 token 写入配置或 Markdown。

启动工作台不会自动让机器狗起身或巡检。部署、启动定位和开始巡检是三个不同动作。

## 2. 录制一套新的现场配置

1. 点“开始录制地图”。
2. 用手柄带机器狗按未来可行路线行走；录制运动始终由人操作。
3. 到需要检查的位置时停车，把机身保持稳定。
4. 用工作台调整 Z1Pro，直到实时画面是以后希望复现的方向。
5. 点“记录检查点/参考图”。页面应显示点位、云台角度和 JPEG 已保存。
6. 继续遥控到下一位置并重复；当前产品通常每点一张指定方向照片，不要求原地 360°。
7. 完成后点“停止录制并同步到 Mac”。等待封存和哈希完成，不要重复点击。

## 3. 建图和地图审核

1. 等待页面完成“机器狗 → Mac → 阿里云 GLIM → Mac”。
2. 选择新地图，检查 2D 概览和 3D 点云。
3. 建图时有人、车或其他临时物体时，可点“打开官方 GLIM 3D 清图”。
4. 在编辑器中只清理动态干扰，尽量保留墙体、楼体、柱子、路沿等稳定结构。
5. 在 GLIM 中按界面要求保存到当前会话的 `SAVED_MAP`，回工作台点“已保存，生成新地图版本”。原地图不会被覆盖。

GLIM 编辑器只改点云。蓝线、绿色区域和业务巡检点都在 GoGoGuard 工作台处理。

## 4. 准备路线、允许区和巡检点

1. 编辑蓝色巡检路线，确认顺序和转弯符合实际可走路径。
2. 画绿色允许区域。蓝线到边界至少给 0.48 m 机器人圆留足空间，窄口要按真实机身和环境验证。
3. 查看巡检点审核：参考图、录制时间、绑定地图位置、朝向和距离必须合理。
4. 保存 workspace。每次保存会形成新 revision，不会改写地图原件。
5. 页面报告路线越界、绿区自交、优化轨迹缺失或巡检点无法绑定时，应修正材料；不要绕过发布校验。

历史上没有巡检点的旧地图可以继续准备。有巡检点的新录制必须带 GLIM 优化时间/四元数轨迹，否则候选会拒绝生成。

## 5. 先在本地完成一遍巡检

1. 发布选中地图和当前 route revision 到机器狗。
2. 点“启动定位与 Nav2”，等待页面明确显示定位可用、代价地图和运动链健康。
3. 点“开始本地巡检”。不要在定位仍连接中时连续点击。
4. 机器狗到巡检点后应先真实停住，再调整机身/镜头。
5. 页面左侧显示录制参考图，右侧显示实时画面。确认后选择继续、重拍或跳过。
6. 继续后机器狗只走剩余路线；最终应明确完成并释放运动控制。
7. 本地完整走通后，才上传平台资产并由明确操作激活。

平台模式与本地操作员模式不能同时控制同一任务。测试平台任务前先确认本地任务已结束。

## 6. 日常停止与恢复

- “停止巡检”：停止当前任务并释放运动控制，不等同于删除地图。
- “停止定位/Nav2”：卸载当前导航运行时；需要重新启动后才能巡检。
- “重新定位”：机器狗保持稳定，清理当前定位恢复状态；不要用它掩盖反复错跳。
- “自动清理并恢复”：清理已拥有的旧进程和代价地图，再启动同一候选；执行中不要重复点。
- 手柄始终是现场人工兜底。任何行为与预期不符时先人工停止，再保留数据分析。

## 7. 出错时先看什么

1. 看“最近操作”是已接收、执行中、已完成还是失败。
2. 看诊断中心分层结论：设备、FAST-LIO、地图定位、Nav2、代价地图、最终速度和 Unitree。
3. 到点方向问题看目标/实际机身 yaw、云台 yaw/pitch、收敛误差和参考图，不先归因于避障。
4. 行人或障碍后停住看对应时间的定位、代价地图和 controller；不要只看最终 `BLOCKED`。
5. 需要开发分析时点事故采集/同步，记下准确时间和操作，不要反复重启覆盖现场。

## 8. 当前参数口径

当前移动基线使用：

- 清晰直线目标上限 0.60 m/s；
- 转弯角速度 0.40 rad/s；
- 侧向速度 0.20 m/s；
- 单一最终安全圆半径 0.48 m；
- 持续重规划间隔 0.75 秒；
- Unitree 接收端指令看门狗 250 ms。

这些是代码配置，不代表整条路线平均速度已经达到 0.60 m/s。参数调整必须保存成版本、保留回执并用同一路线对比；不要把定位或避障缺陷用提高速度、放大跳变或关闭最终边界来掩盖。

## 9. 现场结束

1. 显式停止当前巡检和导航运行时。
2. 确认最终速度为零、Unitree 控制已释放、没有旧任务处于 running。
3. 需要分析时先把事故包和运行回执同步到 Mac。
4. 再关机、断网或把机器狗送去充电。

工作台关闭不会自动代表机器狗所有进程都已停止；以机器狗状态和停止回执为准。
