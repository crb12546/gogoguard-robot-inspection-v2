# 现场交付工作台使用说明

## 明天的正常流程

1. 机器狗开机、接好 Livox 和网线，在 Mac 打开 `http://127.0.0.1:8080/`。
2. 顶部确认机器狗在线、Livox 与 IMU 有频率，实时点云正在刷新。
3. 需要新地图时，点“开始录制地图”，用遥控器带机器狗走完路线，再点“停止录制并同步到 Mac”。
4. 等待页面完整显示“机器狗 → Mac → 阿里云 GLIM → Mac”的进度。完成后点选右侧的地图版本，检查 2D 概览与可旋转的 3D 点云。
5. 在“巡检地图工作台”准备地图材料：
   - 如果建图时有人或车，点“打开官方 GLIM 3D 清图”。在 GLIM 中删除临时点云，然后点 `File -> Save map`，选择会话目录下的 `SAVED_MAP`。
   - 回到工作台点“已保存，生成新地图版本”。这会保留原地图，不会覆盖。
   - 确认蓝色巡检路线，画出绿色允许行走范围，然后保存。蓝线与绿色边界至少留出 0.48 m。
6. 按“巡检操作向导”中高亮的下一步操作：
   - 所选地图尚未在机器狗上：发布地图与路线。
   - 已发布：直接“启动定位与 Nav2”，不会再出现多余的“使用当前地图”操作。
   - 等待“定位可用”，不要重复点击。
   - 点“开始巡检”。
7. 巡检中可看到任务状态、路线百分比、剩余路径点、实时位置与最终速度。“暂停巡检”不会卸载地图。

## 出错时怎么做

- 按钮点击后，看“最近操作”：已接收、执行中、已完成或失败。执行中不要重复点。
- 位置显示不对：点“重新定位”，机器狗保持站稳。
- 任务显示 `FAULT` 或 `BLOCKED`：展开“诊断中心”并点“立即分析”。页面会分别显示定位、Nav2、避障、运动桥与最终运动链的结论。
- 需要恢复：点“自动清理并恢复”。它会停止旧运行时、清理局部代价地图并重启同一地图，不需要手工重启网页或连续点按钮。

## 参数中心

日常可调整 MPPI 前进上限、接收链路硬上限、加减速、转弯/侧向速度、定位断流容忍和持续重规划间隔。页面不再显示已停用的 RPP 绕行速度、矩形停车区和减速区参数。参数保存前会校验，每次保存都生成新版本，可一键回滚。

## 当前默认值

- 直线速度：0.60 m/s
- 转弯角速度：0.40 rad/s
- 侧向速度：0.20 m/s
- 机器狗唯一安全圈半径：0.48 m
- 路线阻塞持续确认：0.50 秒；重规划间隔：0.75 秒
- 定位状态超时：0.60 秒，短暂丢失容忍 1.0 秒

这些是代码与离线测试通过的明日候选值，不是机器狗实地验收结论。
