# 巡检导航地图工作台：现场用法

> 这是给现场操作人员的说明，不要先去调 Nav2 工程参数。

## 你真正要做的六步

1. 在“现场资产历史”里选一张已经建好的地图。
2. 点“全屏编辑”，用滚轮或“＋”放大；点“拖动地图”后可平移，“适应全图”可一键回到全景。
3. 把鼠标移到想确认的位置：底部会显示坐标、附近点数和高度范围，右上角 3D 点云的黄色圈会对应同一位置。可切换俯视、斜视、只看高度层，也可单独放大 3D。
4. 只在红色明显错了时手动涂改。工作台会强制先放大到 200% 以上，避免在全图上一笔误擦大片区域。
5. 点“绘制绿色可走外圈”，沿着允许狗行走的区域外圈依次点击。绿线不要贴墙，至少给狗留出 0.48 米。
6. 点“预演自动路线”。出现紫色线和“可到达”后，点“确认并保存这张导航地图”。

保存后，再按原有流程发布到机器狗。每次更换地图、修改绿色区域或红色障碍后，都需重新保存和发布。

## 图上四种颜色是什么

| 颜色 | 意思 | 你需要管吗 |
|---|---|---|
| 红色 | 点云高度切片产生的“不可走占用候选”，不是物体语义识别 | 结合 3D 判断，只有明显错了才涂改 |
| 绿色 | 狗绝对允许行走的外圈 | 需要你确认 |
| 蓝色 | 录制时的推荐方向、巡检点顺序和最终目标 | 录制路线正常就不用重画 |
| 紫色 | 从当前起点到目标的连通性预演 | 保存前看一次 |

工作台里的紫线只是让人快速看懂“这张图能不能走通”。机器狗正式巡检时，路径会由 Nav2 SmacPlanner2D 根据它当时的真实位置重新计算，不会照抄紫线。

## 什么时候才用“刷成固定障碍 / 擦掉误判障碍”

默认不用。工作台会自动：

- 只取地面上方 0.05–1.80 米的高度层，所以地面和屋顶不参与平面导航；
- 把点云聚合为 0.10 米小格；
- 去掉孤立的单格噪点；
- 把机器狗录制时真正走过的身体通道从自动障碍中清出来。

工作台不会告诉你某一块是“墙”还是“柜子”。它只负责把高度层里的点投影到平面，让你判断这里对机器狗是不是可走。不确定时，切到 3D 斜视再判断，不要凭红块猜物体类型。

只在下面两种情况手动涂：

- 图上明明是空地，却有一片红色：选“擦掉误判障碍”；
- 明明是固定不可走的位置却没被标红：选“刷成不可走”。

“自动隐藏屋顶（推荐）”是室内默认。“室外高障碍”只是把上限放到 2.50 米，用于室外高的墙体或设施。

## 为什么不改原始 PCD

原始 PCD 给 VGICP 做定位；这里生成的二维导航地图给 Nav2 规划“哪里能走”。两者分开，手动擦掉一个导航误判不会把定位地标删掉。

GLIM 官方 3D 清图仍保留，但只在原始地图真的录入了大量临时人车、并影响 VGICP 定位时使用。它不是每次画导航区的必经步骤。

## “不可到达”时先看什么

1. 起点或终点是不是落在绿色区外。
2. 绿色外圈是不是画得太贴墙，没有给 0.48 米机身留出空间。
3. 红色是不是把本来能走的门洞堵上了；确认是空地后再擦。
4. 不要通过把机身圆缩小来勉强通过；空间确实不够就应该换目标或改可走区。

generation 9 已在 Mac 上用真实地图生成静态导航图，并于 2026-08-13 安装到机器狗。安装后已核对不启动定位、Nav2 和运动桥，属于趴下状态的静态验证。它还没有通过真实完整巡检、绕人、绕车和宽障碍绕行验收。
